# Host interface sounds

`shutter.wav` is the unchanged camera sound embedded in
[1984's shutter_wav.h](https://github.com/salvogendut/1984/blob/1023da5c513de64c388ffc8b269d7357e5a98770/src/shutter_wav.h).
It is 44.1 kHz, mono, signed 16-bit PCM (14,976 samples). Heliacal embeds it
in the executable and plays it after successfully saving an F4 screenshot.

SHA-256: `95a83b03c8324f642a7713f033960bc4710d73395945a9b21fa55874d03fac4e`.
